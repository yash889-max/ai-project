# AI Project Website

A modern, responsive website built with Next.js and Tailwind CSS, featuring a professional contact form.

## Features

- 🚀 **Next.js 14** - React framework with server-side rendering
- 🎨 **Tailwind CSS** - Utility-first CSS framework
- 📱 **Fully Responsive** - Mobile, tablet, and desktop support
- 📧 **Contact Form** - Built with React Hook Form and validation
- 🌙 **Dark Mode** - Professional dark theme
- ⚡ **Fast Performance** - Optimized for speed and SEO

## Pages

- **Home** - Hero section with call-to-action buttons
- **About** - Company information and values
- **Contact** - Professional contact form with validation

## Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/yash889-max/ai-project.git
cd ai-project
```

2. Install dependencies
```bash
npm install
```

3. Run the development server
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm start` - Start production server
- `npm run lint` - Run ESLint

## Contact Form

The contact form includes:

- Name, email, subject, and message fields
- Form validation with error messages
- Success notification on submission
- Responsive design
- Accessible form inputs

## Deployment

Deploy easily to Vercel:

```bash
npm install -g vercel
vercel
```

Or deploy to any Node.js hosting platform.
